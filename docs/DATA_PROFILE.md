# Data Profile

What the raw data looks like before any cleaning, and the problems the pipeline has to handle.

- **Samples:** [`data/samples/ctgov_sample.json`](../data/samples/ctgov_sample.json) (20 ClinicalTrials.gov trials) and [`data/samples/openfda_sample.json`](../data/samples/openfda_sample.json) (20 openFDA FAERS adverse event reports out of 153,207 matching the query)
- **Generated by:** `python scripts/profile_samples.py` (read-only; rerun it to reproduce every number below)
- **Last run:** 2026-11-19

These are small samples, so the counts show which problems exist, not how common they are in the full data.

> **FAERS caveat:** an adverse event report means a patient was taking a drug when something happened. It does not show that the drug caused the event.

## Details

### 1. Brand vs. generic names

FAERS stores each drug's name in `patient.drug[].medicinalproduct`, exactly as the reporter typed it. Reporters often type a brand name. Trials mostly use generic names, so the same drug can show up under different names in the two sources.

**How it's measured:** the script compares each typed name with openFDA's own `openfda.brand_name` and `openfda.generic_name` lists for the same entry, ignoring case, extra spaces and a trailing period. A name found in both lists counts as generic, since some generics are sold under their generic name. The brand labels come from openFDA's data, not from outside knowledge.

| Typed name was... | Drug entries | Share |
|---|---|---|
| A generic name | 68 | 43% |
| A brand name | 41 | 26% |
| Unknown: openFDA attached no drug data | 47 | 30% |
| In neither openFDA list | 2 | 1% |
| **Total** | **158** | |

**Brand-name examples** (confirmed by `openfda.brand_name`): `ALIMTA`, `BENICAR`, `BENICAR HCT`, `CRESTOR`, `ENBREL`, `FOSAMAX`, `FOSAMAX PLUS D`, `INSPRA`, `JANUMET`, `JANUVIA`. For example, `JANUVIA` has generic name `SITAGLIPTIN`, and `TASIGNA` has `NILOTINIB`.

**Why 26% is a floor:** the 47 entries with no openFDA data can't be classified from this file, and they likely include more brand names. `LASILIX` is one: it's a French brand name for furosemide, but nothing in the sample confirms that. RxNorm lookups in Session 3 should resolve these.

**In neither list:** `FLONASE` and `VOLTAREN` are brand names, but openFDA attached a longer product name (`FLONASE ALLERGY RELIEF`, `VOLTAREN ARTHRITIS PAIN`), so they don't match exactly. openFDA also attached generic names for an unrelated combination product to the `FLONASE` entry (`ACETAMINOPHEN, CHLORPHENIRAMINE MALEATE, PHENYLEPHRINE HCL`, alongside `FLUTICASONE PROPIONATE`). So the `openfda` fields can be wrong as well as missing.

### 2. Case and punctuation differences

The same drug appears as `Epoetin Alfa` and `epoetin alfa` within the trials sample. FAERS names are usually uppercase and can have stray punctuation, like `METFORMIN HYDROCHLORIDE.`

### 3. Dose or form text in the name

Trial intervention names can include dose or delivery form: `Empagliflozin 10 mg`, `Semaglutide Pen`, `folate treatment`. These need to be stripped before lookup.

### 4. Combination products

Some FAERS names are single brands that contain two or more drugs: `JANUMET` (openFDA generic name: `SITAGLIPTIN AND METFORMIN HYDROCHLORIDE`), `PRAVADUAL`, `BIPRETERAX`. One name has to map to several ingredients. `PRAVADUAL` and `BIPRETERAX` have no openFDA data, so their ingredients aren't confirmed by the sample.

### 5. Missing `openfda.generic_name`

47 of 158 FAERS drug entries (30%) have no `openfda` data at all. Examples: `URSO`, `DIAMICRON`, `PRAVADUAL`, `CISPLATINE`, `METFORMINE`, `LASILIX`, `EPINITRIL`, `CARDENSIEL`, `BIPRETERAX`, `ACICLOVIR`. Many are non-US brands or spellings.

### 6. Dates as text; partial dates

FAERS `receivedate` is a `YYYYMMDD` string (for example, `"20140312"`). Trial start dates are a mix of full dates (11 of 20, `YYYY-MM-DD`) and month-only dates (9 of 20, `YYYY-MM`).

### 7. Age stored with a separate unit code

FAERS stores age in `patient.patientonsetage` and its unit in `patient.patientonsetageunit` (`801` = years, `802` = months, `804` = days, and so on). All 15 reports with an age use `801`. 5 of 20 reports have no age.

### 8. Non-drug interventions

Of 36 trial interventions, only 15 are typed `DRUG`. The others are `OTHER` (7), `BEHAVIORAL` (4), `PROCEDURE` (3), `DIETARY_SUPPLEMENT` (3), and one each of `DIAGNOSTIC_TEST`, `DEVICE`, `RADIATION` and `BIOLOGICAL`. 2 interventions are placebo.

### 9. Multiple conditions per trial

12 of 20 trials list more than one condition, and one lists 9. Conditions are free text, so kidney trials can't be found from a single field.

### 10. Duplicate reports and versions

Every report in the sample has `duplicate=1`, and `safetyreportversion` ranges from 2 to 12. The pipeline should keep one version per `safetyreportid`.

### 11. Non-English drug names

`CISPLATINE` and `METFORMINE` are French spellings of cisplatin and metformin. They won't match English names without a lookup.

### 12. No exact name overlap between sources

After lowercasing and trimming, 0 of the 13 distinct trial drug names match any of the 114 distinct FAERS drug names. Problems 1–5 and 11 together explain why, and this is the case for RxNorm normalization in Session 3.
